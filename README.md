# Asansör Kat Atlatma Antlaşması

> Resmi sınıflandırma: `ISO-KAT/404 — Kapı Açılmadı Protokolü`
>
> Aciliyet: sen çıkış katındasın, asansör değil.

Bu depo, modern medeniyetin en eski düşmanıyla müzakere eder: **senin katını bilerek atlayan asansör**.

Bilim insanları (biz) yıllarca (on iki dakika) araştırdı. Sonuç net. Asansör küsmez. Asansör pazarlık yapar. Sen `4`e basarsın, o `7`de birini alır, sana da `teknik arıza` der. Bu bir arıza değildir. Bu bir dış politikadır.

## Ne işe yarar

`python3 diplomasi.py` çalıştırırsın. Program:

1. Hangi katta olduğunu sorar.
2. Asansörün seni kaç kez ektiğini sorar.
3. Elindeki rüşvet çikolatayı tartar (mental tartı, gerçek tartı yasak).
4. Diplomatik nota, özür metni ve mahkeme kararı üretir.
5. Asansör hâlâ inat ederse merdivenleri `stratejik ortak` ilan eder.

Bağımlılık yok. Python 3 yeter. İnternet yok. Asansör de yok, o ayrı konu.

## Kurulum (abartılı)

```bash
git clone https://github.com/Tentivory/asansor-kat-atlatma-antlasmasi.git
cd asansor-kat-atlatma-antlasmasi
python3 diplomasi.py
```

Kurumsal dağıtım için: dosyayı yazıcıdan çıkar, asansör kabinine bantla, bekçiye `bu uluslararası antlaşmadır` de. Bekçi inanmaz. Protokol başarılı sayılır.

## Hukuki uyarı

Bu yazılım asansör üretmez, kat üretmez, adalet üretmez. Sadece adaletin sesini taklit eder. Taklit o kadar iyidir ki bazen kendi kendine `sayın başkan` der.

## Sık sorulan sorular

**Asansör gerçekten durur mu?**  
Hayır. Ama sen artık durmuyorsun. Bu bir kazançtır.

**Neden Türkçe?**  
Çünkü asansör zaten anlamıyor. Bari biz anlayalım.

**Gizli dosya ne?**  
Arşiv. Arşivler merak edilince açılır, açılmayınca da arşiv kalır. `arsiv/nota.b64` dosyası teknik ek'tir. Dokunma. Dokunursan da base64 çöz, sonra yine dokunma.
